# Changelog

## 1.0.0

- Track daily water, push-up and pull-up sets, and independently enabled creatine and protein habits.
- Open today's Water history from the progress circle and exercise history from the clock icon on each Set history pill. See each entry's time and remove individual entries.
- Review streaks, achievements, goal completion, historical statistics, and calendar records.
- Configure reminders with Android notification-permission handling.
- Export and import validated local backups.
- See your streak and all three habits side by side in the home-screen widget. Tap it to open HydraPush.
- Keep the app offline-first with no `INTERNET` permission or network services.
- Preserve history when goals or optional-habit requirements change. Today’s correction and Undo affect only today’s entries.

The public ARM64 build uses application ID `com.hydrapush.tracker`, version code 2, and Room schema 2. To move from a private review build to the public release, export a backup in Settings, uninstall the review build, install the public APK, and import the backup.
